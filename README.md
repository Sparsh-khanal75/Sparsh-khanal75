# 📄 Research

**A Multi-Modal Entropy-Weighted Fusion Framework for Melanoma Detection**, *IEEE, IITCEE 2026*
Co-authored with Samved Vyas, Reet Nayan and Dr. Prem Kumar Ramesh
An ensemble of Vision Transformer, ResNet-50 and MobileNetV3, combined through entropy-weighted fusion, reaching **91.2% accuracy**. My contribution: designing and implementing the model-fusion strategy and evaluating ensemble configurations. I later applied the same fusion method to network intrusion detection ([ml-intrusion-detection](https://github.com/Sparsh-khanal75/ml-intrusion-detection)).
